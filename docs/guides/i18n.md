# i18n

**读它的时机**：增删任何界面文案。

## 全局偏好

**在 `web/src/prefs/`**：语言（zh-CN / en-US）+ 外观（light / dark / system），
存 `ama.prefs.v1`，与按空间的 `ama.store` 分开。页面 `/preferences`，**刻意放在
workspace 之外**——这是用户级偏好，切空间不该变。入口在空间列表页与侧栏「账号」组。

**它只有一个路由，外壳靠 `?from=<workspaceKey>` 切**：带这个参数时渲染在 AppShell 里
（从空间内进来的，侧栏该留着），不带时无壳。key 取不到（不存在 / 非成员 403）就降级成
无壳，不报错。理由与两次「侧栏消失」的翻车经过见 `web/src/app/PreferencesRoute.tsx`
与 `docs/DESIGN.md`。

## 所有界面文案走 `t()`

用 `useT()` 或 `usePrefs()`。翻译表在 `prefs/messages.ts`，平铺键值，键名 `模块.用途`。
**键集合以中文表为准**：en 表缺键 TypeScript 直接报错。

## 几条动手前必须知道的

- **模块级常量不能调 `t()`** —— 求值时 context 还不存在。存翻译键，渲染时再翻
  （见 `AgentDetailPage` 的 `TABS`、`lib/timeline.ts` 的 `STOP_REASON_KEYS`）。
- **`lib/timeline.ts` 是纯模块**，`t` 由调用方传入（`buildTimeline(events, t)`）。
- **hooks 只能在组件体顶层**。曾把 `useT()` 写进 `validate()` 这类嵌套函数里，
  运行时报 "Invalid hook call" 且整个弹窗白掉 —— typecheck 抓不到，只有跑起来才暴露。
- **别用脚本批量替换中文串**。试过，代价是把 JSX 属性写成 `title=t("k")`（缺花括号）、
  把 hook 插进解构参数列表、还改坏了别的会话正在编辑的文件。**逐文件手改。**
- **相对时间/日期/千分位用 `Intl`**，不要手写两套中英串 —— `lib/format.ts` 的函数
  都接一个可选 `locale`，调用方从 `usePrefs()` 取 `language` 传进去。
- **e2e 里大量中文选择器依赖默认语言是 `zh-CN`**。改默认语言会连带弄坏它们。
